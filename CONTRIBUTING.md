# Contributing

Thank you for your interest in improving nara-notice-collector.

## Development flow

1. Install dependencies with `npm install`.
2. Make focused changes on a feature branch.
3. Run `npm run typecheck`.
4. Run `npm test`.
5. Open a pull request with a short summary and validation notes.

## Scope guardrails

Do not add private customer workflows, sales opportunity scoring, related-notice matching, LLM fallback logic, or private repository artifacts.
